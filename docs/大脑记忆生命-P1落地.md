# 大脑 / 记忆 / 生命 · P1 落地说明

> 本轮目标：先把「连续性正确、记忆不丢、自主不空转」做成可验证的最小闭环，
> 不改变权限模型、不自动合并、不把 `brain/` 纳入仓库。

## 1. 一条主线

**一个大脑、一份记忆、一条时间线。**

- `brain/` 是唯一可迁移的持久层：身份、目标、决策、自我模型、记忆、时间线、快照。
- `memory.json` 保留为**兼容投影**：已有工具/接口不改，但新写入与用户确认的候选
  都会镜像到 `brain/memories/memory.jsonl`。
- 不做破坏性迁移：旧 `memory.json` 事实在睡眠整理时按同文本幂等补入大脑。

## 2. 记忆管线

### 写入

- `write_memory`：`memory_facade` → 大脑镜像（原有路径）。
- 对话自动提炼默认 `pending`；用户 `accept` 时 `resolve_pending(sync=True)`
  同步写大脑（此前只写 `memory.json`，快照/合并会缺这段记忆）。
- 大脑写入去重改为**文本索引缓存**：只有 `memory.jsonl` 变化时重建，不再每次写入全量扫描。

### 命中

- `search_memories(record_hits=True)` 不再重写整个 `memory.jsonl`，改为追加
  `brain/memories/hits.jsonl`；
- `load_memories` 读取时叠加增量；
- 睡眠/整理调用 `compact_hits()` 折回主文件并清空增量。

### 读取

- `memory_store` 按**显式 `brain_dir`** 读取（`load_memories_from`），不再临时切换全局
  `BRAIN_DIR`；`brain-switch` 后会重新绑定统一读取层。
- 旧数据（无 `origin` / `hit_count` / `version_id`）在读取时补默认值，不改写文件。

### 整理

- 相似记忆合并先用倒排索引生成候选对，避免全量两两比较；
- 睡眠时归档低价值记忆、折叠命中、裁剪时间线/意图/决策/代价/指标。

## 3. 生命连续性

- **暂停持久**：`loop.start()` 尊重 `life.json` 的 `paused`，只有 `resume` 能清除。
- **反思冷却持久**：`_reflect_worker` 写回 `last_reflect`；重启后从状态恢复，不再重置。
- **节律醒来**：睡眠写入 `next_wake_at`（`life_wake_time` 或 `life_sleep_duration_minutes`），
  tick 到点自动醒来；用户活动仍可提前唤醒。
- **有限自主**：新增 `review_memory`（检索相关记忆并复盘）、`housekeeping`（归档/折叠/
  补同步）、`recalibrate_self`（LLM 校准自我模型）。仍不调用外部工具、不改权限。
- **结果回灌**：反思提示加入相关记忆与最近 outcome；近期失败计入 mastery 内驱。
- **睡眠质量**：预算允许时用 LLM 提炼记忆；只有真实增量才产生进化提案。
- **指标**：`brain/metrics.jsonl` 记录 tick/reflect/sleep 耗时与结果，随 `/v1/life` 返回。

## 4. 不变量

1. 不自动合并自进化分支，不自动修改权限。
2. 记忆作废只认显式 key，不按相似度自动作废。
3. `life.lock` 仍是单实例写入租约；observer 只读。
4. 时间线 append-only；epoch 仍是分支/合并/恢复的唯一追溯依据。
5. 快照仍排除 `.keys` / `archive` / `life.lock` / 血缘与合并临时文件。
6. 指标写入失败永不阻断生命周期；所有新增静默降级均过 `check_silent_except` 门禁。

## 5. 兼容与回滚

- 新增文件：`hits.jsonl`、`metrics.jsonl`、`intentions_archive.jsonl`、
  `decisions_archive.jsonl`、`scars_archive.jsonl`。
- 旧文件格式不变；`load_memories` 新增参数均有默认值。
- 回滚代码后，上述增量文件可保留（不影响旧逻辑读取主文件），也可手工删除。

## 6. P0/P1 续作（本轮）

- **统一记忆读路径**：`context.memory` 在宿主声明 `unified` 时走 `memory_store.search`
  （memory.json + 大脑 jsonl 去重）；`brain_context` 关闭重复的近期记忆，只保留
  身份/断点/目标/自我认知/决策/复习。
- **投影迁移游标**：`memory_sync_state.json` 记录已处理文本哈希；启动后台全量补同步，
  睡眠增量 50 条，重复执行幂等。
- **只读工具型意图**：`tool` kind 仅允许 `read_memory` / `query_memory_graph` /
  `knowledge_search` / `project_map`；超时、输出截断、连续两次无变化后拒绝。
- **睡眠深化**：超 3 天未回执决策、停滞 7 天目标写入睡眠复盘；演化提案同标题去重 +
  裁剪；自我模型冲突时明确以核心自我状态为准。
- **观测**：`/v1/life` 返回 `metrics` 与 `storage`（待折命中、已归档意图），
  LifePage 展示下次醒来与 tick/reflect/sleep 指标。
- **基准**：`tools/memory_bench.py` 可生成临时大脑做 1 万/5 万条实测，不触碰真实 `brain/`。

## 7. 基准（tools/memory_bench.py，临时大脑）

| 规模 | 写入平均/ p95 | 检索平均 | 注入 | 巩固 |
|---|---|---|---|---|
| 1 万 | 8.8 / 15.7 ms | 29 ms | 74 ms | 8.4 s |
| 5 万 | 13.3 / 25.1 ms | 489 ms | 162 ms | 未跑（可选） |

检索在「查询词命中全库」时仍是 O(候选数)；注入与写入满足目标，5 万条检索
建议后续用更细的倒排/分片继续优化。

## 8. 验证

- 新增生命连续性、记忆管线、演化账本与统一上下文回归用例；
- 全量 pytest、`audit_tools --strict`、`validate_tools`、`island_check`、
  `check_docs`、`check_silent_except` 均通过；
- 建议后续补：真实时间 soak（暂停/重启/换脑/跨日睡眠）、大记忆量注入耗时基准。
