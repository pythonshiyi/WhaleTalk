# 鲸语 WhaleTalk 设计系统（单一事实源）

> 目的：让"一致性地基"可长期维持——任何人加组件/改界面时，照本文件就能**不破坏一致性**。
> 原则：**UI 一律引用令牌，禁止裸写色值/尺寸；例外必须登记**。
> 令牌定义位置：`webui/src/theme.css`（三主题：星海 starfield 默认 / 深海 deepsea / 北极冰 arctic）。

---

## 0. 三条铁律（违反即需在代码注释说明理由）

1. **颜色走语义，不走色值**：不用 `#xxx`，用 `--brand/--ok/--danger/--warn/--ai` 或 `--text-*`/`--border`。需透明度用 `rgba(var(--brand-rgb), .N)`。
2. **尺寸/间距/字号/圆角走令牌**：`--sp-*`、`--fs-*`、`--r-*`。避免散落裸 `padding:8` / `fontSize:12`。
3. **三态必齐**：列表/面板类组件必须覆盖「空态 / 加载态 / 错误态」（用 `.empty-tip` 三态族，见下）。

---

## 1. 语义色（含义恒定，跨主题只调明度）

| 令牌 | 含义 | 用法 |
|---|---|---|
| `--brand` / `--brand-strong` | 主操作 / 链接 / 选中 / AI 主题 | 主按钮、链接、激活态 |
| `--ai` | AI / 模型相关 | 工具图标、模型标签 |
| `--ok` | 成功 / 安全 / 已启用 | 完成态、绿色对勾 |
| `--warn` | 警告 / 接近上限 | 提醒、接近阈值 |
| `--danger` | 失败 / 破坏 / 删除 | 错误、删除按钮 |
| `--text-1/2/3` | 主/次/弱 文字层级 | 正文/说明/占位 |
| `--text-link` | 链接色 | 文中链接 |

软底（`--*-soft`）与 RGB 分量（`--*-rgb`）配套使用：底色用 `var(--X-soft)`，需要透明度叠加用 `rgba(var(--X-rgb),a)`。
语义别名（`--accent≈--brand`、`--success≈--ok`、`--panel≈--bg-2`、`--bg≈--bg-0`）为兼容历史组件，**新代码用规范名**。

## 2. 表面 / 边框 / 阴影

| 令牌 | 含义 | 层级 |
|---|---|---|
| `--bg-0` | 页面底色 | 最深（深色主题）/ 纯白（北极冰）|
| `--bg-1` | 卡片/主面板 | 主要承载面 |
| `--bg-2` | 内嵌块/输入框底 | 次级承载面 |
| `--bg-3` | 分隔/表头/hover 深化 | 对比强调 |
| `--bg-hover` / `--bg-active` | 悬停 / 激活 | 可点项 |
| `--border` / `--border-strong` | 常规 / 强调 边框 | |
| `--header-bg` / `--bubble-bg` / `--chat-glow` / `--composer-fade` | 头部/气泡/辉光/输入渐变 | 专用 |
| `--shadow-1/2/3` | 轻/中/重投影 | 层级抬升 |

## 3. 圆角 / 间距 / 字号 / 字体 / 动效

| 族 | 令牌 | 建议 |
|---|---|---|
| 圆角 | `--r-sm 6 / --r-md 10 / --r-lg 14 / --r-xl 18 / --r-full 999` | 卡片 `--r-lg`，控件 `--r-sm/md` |
| 间距 | `--sp-1..6 = 4/8/12/16/24/32px` | 组内小、组间大 |
| 字号 | `--fs-xs 12 / sm 13 / md 14 / lg 16 / xl 20 / 2xl 26` | 正文 `--fs-md`，说明 `--fs-sm`，弱 `--fs-xs` |
| 字体 | `--font-ui`（界面）/ `--font-mono`（代码/数字） | 代码/行号用 mono |
| 动效 | `--ease = cubic-bezier(.22,1,.36,1)` | 时长 120–240ms；只动 transform/opacity；尊重 `prefers-reduced-motion` |

## 4. 代码高亮（恒深底，跨主题亮色系）

`--hl-kw/str/com/num/fn/ty/at/tag` + `--code-bg/--code-text`。代码块三主题都保持深底（刻意设计）；浅色主题下正文用浅色即可，勿把代码块底改浅。

## 5. 三态提示族（统一视觉语义）

| 类 | 语义 | 视觉 |
|---|---|---|
| `.empty-tip`（裸） | 空态 / 中性说明 | 弱化文字 |
| `.empty-tip.is-loading` | 加载中 | `::before` 转圈 + 次强调色 |
| `.empty-tip.is-err` | 错误 | 危险色 + ⚠ |
| `EmptyState` 组件 | 图文空态（图标+标题+引导） | 面板/列表大空态用 |

---

## 6. 设计评审 Checklist（加功能/改 UI 前逐条过）

- [ ] 颜色：无裸 `#hex`；语义色 + 主题正确（切到 arctic 浅色再自查一遍对比度）
- [ ] 尺寸：间距/圆角/字号用了 `--sp-*`/`--r-*`/`--fs-*`，无散落裸数值
- [ ] 焦点：可交互元素有可见焦点（`:focus-visible` 已全局兜底，勿手写 outline 破坏）
- [ ] 三态：列表/面板覆盖 空/加载/错误，错误不复用"空态"文案
- [ ] 动效：只动 transform/opacity，时长≤240ms；`reduced-motion` 下应完全静止
- [ ] 文本：正文用 `--text-1`，勿用 `--text-1` 之外的近似色替代；代码走 mono
- [ ] 键盘可达：Tab 顺序合理，弹窗可 Esc/✕ 关闭，不出现"无出口"态
- [ ] 深/浅主题：至少切星海 + 北极冰目检一次

## 7. 维护约定

- 新增组件样式放 `app.css` 对应 `═══` 区段下（见文件顶部 TOC 索引）。
- 新增令牌：先在 `theme.css` 定义（三主题都要给值），勿只在组件内联 `var(--x, #兜底)`——历史教训：幽灵变量静默落 hex 兜底、不随主题。
- 全局改 `transition` 只列具体属性，勿用 `all`。
