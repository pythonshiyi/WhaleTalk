# 配置与上限速查

> 设计原则：**程序告诉 AI「能做什么」，不规定「必须怎么做」。**
> 一切数值上限与护栏都属于**用户配置**——不因个别实验就替用户/模型定死边界。
> 统一前缀 `WHALETALK_<常量名>`；**0（或负）通常表示「不限」**（具体见表）。
> 设置方式：启动前设环境变量，或在启动脚本里 `set`/`export`。

---

## 8. 通用输入钳制

`clamp_int / clamp_float / clamp_str` 是各工具的输入范围校验。

- `WHALETALK_NO_CLAMP=1`：**全局跳过上下限/截断**（仍做类型归一，非法值回默认）——一处开关放开所有工具的输入范围。

## 9.5 硬件加速（GPU / 多核，渲染提速）

| 环境变量 | 默认 | 作用 |
|---|---|---|
| `WHALETALK_FFMPEG_HW` | `auto` | 视频编码器：`auto`（探测 AMD AMF→NVIDIA NVENC→Intel QSV，实测通过才用）/ `amd` / `nvidia` / `intel` / `off`·`cpu`（强制 CPU libx264）。检测到 GPU 时 MV 合成/转码走硬件编码 |
| `WHALETALK_HTML_GPU` | `1` | HTML/图像渲染让 Chromium 走 D3D11/ANGLE 用独显（`0` 关闭，回退纯 CPU SwiftShader） |
| `WHALETALK_MV_RENDER_WORKERS` | `0`（自动） | MV 分段渲染并行数（独立 ffmpeg 进程，吃满多核）；`1` = 串行 |

> 说明：`ffmpeg_hw_report()`（或渲染结果自检）可查看当前实际使用的编码器；无 GPU 时自动回退 CPU，不影响正确性。

## 11. `config.json` 中的开关（非环境变量）

| 键 | 默认 | 说明 |
|---|---|---|
| `network.block_private` | true | SSRF/私网+云元数据拦截。**设 false = 关闭** |
| `filesystem.max_write_size` | 50MB | 写盘上限（另有 `WHALETALK_MAX_WRITE_SIZE`） |
| `blocklist_enabled` | true | 黑名单总开关。**设 false = 一切全放行** |
| `full_auto` | — | 零审批（任务模式自动全放行） |
| `approval_actions` | [] | 需要审批的动作清单 |
| `image_api_key` / `image_base_url` / `image_model` | — | 图片生成后端（缺则 `image_generate` 不可用） |

---

> 未列出的常量（如 cron 字段范围、进程/网络语义边界）属于**功能语义**而非可调上限。
> 若仍遇到碍事的硬限制，按 `WHALETALK_<常量名>=0` 即可尝试放开。
